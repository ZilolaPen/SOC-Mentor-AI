
# Anna — SOC Mentor AI

An AI-powered SOC Analyst Training Assistant for cybersecurity students and beginners.

## About the Project

Anna is designed to teach Security Operations Center (SOC) investigation skills through interactive, fictional security incidents.

Instead of simply explaining theory, Anna guides learners through alerts, log analysis, evidence evaluation, and incident response decisions.

## Learning Features

- Simulated security alerts
- Step-by-step incident investigations
- Authentication and security log analysis
- Feedback and scoring
- Cybersecurity interview practice
- Multilingual explanations in English, Russian, and Korean, with Uzbek support
- Beginner-friendly cybersecurity education
