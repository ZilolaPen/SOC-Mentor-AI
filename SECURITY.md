
# Security Policy

## Purpose

Anna is an educational cybersecurity project for defensive security training.

## Authorized Use

- Use fictional scenarios and training logs.
- Practice in systems and environments you own or have explicit permission to test.
- Treat AI-generated findings as hypotheses that require verification.

## Data Protection

- Never commit API keys, passwords, access tokens, or private credentials.
- Do not upload real company logs or personal information without appropriate authorization.
- Avoid exposing sensitive information in public issues or screenshots.

## Reporting Problems

If you discover a security issue in the application, document the affected component and the steps needed to reproduce it. Do not include real credentials or sensitive personal data in a public report.
